**The grid is built as 6 columns with each item spanning 2** (not a plain 3-column grid) so a trailing partial row can be centered instead of left-hugging column 1 — a plain `repeat(3,1fr)` grid can't center a non-multiple-of-3 item count. The centering math for the trailing row depends on how many items are in it, and **this has already produced one real bug**: when the trailing row held 2 items (5 total), centering that pair correctly used `grid-column:2/4` + `4/6`. When the count dropped to 4 (1 item left in the trailing row), that same `2/4` rule was left in place on the assumption it would still center a lone item — it doesn't; it left-biases it (verified: 177px left margin vs 532px right margin, clearly not centered). A single 2-wide item in 6 columns needs 2 empty columns on each side, i.e. `grid-column:3/5`, not `2/4`.

**General formula: for a trailing row of `k` items (each spanning 2 of 6 columns), the first item's start line is `(6 - 2k)/2 + 1`.** k=1 → start line 3 (`3/5`). k=2 → start line 2 (`2/4`, second item follows at `4/6`). **Whenever the item count changes, recompute this from the formula — don't assume the previous row's centering math still applies to a different row size.** As of 2026-07-26 the section has **3 items**, which fill columns 1-2 / 3-4 / 5-6 = one complete row with NO trailing partial row, so **no `nth-child` centering override is needed at all** — the `.choose-item:nth-child(4){grid-column:3/5}` rule was deleted along with the 4th card. If the count ever drops back to a non-multiple-of-3 (4 or 5 items), re-add an override computed from the formula above.

## Business model: subscription, not one-off booking

Pet Waste Wagon CLT is a **subscription business**. Weekly and bi-weekly plans are recurring, self-serve sign-ups (not a "request a quote and wait to hear back" flow) — the customer picks a plan, picks dog count, and subscribes directly on the site. Deep clean is the only one-time/non-subscription offering. The "Get a Free Quote" form still exists for edge cases (5+ dogs, large yards, anything needing a human) but is no longer the primary conversion path for standard customers.

**Owner has confirmed route capacity supports self-serve sign-up** — this was a deliberate choice, not a fallback because of unknowns.
